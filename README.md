# ⚔️ Codewars Java

Soluções dos desafios do [Codewars](https://www.codewars.com/) desenvolvidas em Java.

## 🎯 Objetivo

Praticar lógica de programação, resolução de problemas e aprimorar meus conhecimentos em Java através de desafios de diferentes níveis de dificuldade.

## 📚 Katas

Os desafios estão organizados de acordo com seus respectivos níveis:

- 8 kyu - Iniciante
- 7 kyu - Básico
- 6 kyu - Intermediário
- 5 kyu - Avançado

## 🛠️ Tecnologias

- Java
- IntelliJ IDEA
- Git

## 📈 Progresso

Este repositório será atualizado conforme novos desafios forem resolvidos.
